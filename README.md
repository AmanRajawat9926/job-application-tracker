
# Job Application Tracker

A CRUD web application built to monitor job application, stages, and follow-ups.

## Day 1 Deliverables
- Fresh React setup using Vite
- Controlled add-application form (Company, Role, Round, Applied Date, Job Link).
- Inline per-field validations:
  - Required validation on Company and Role.
  - Applied date validation (disallows future dates).
- Newest-first sorting based on applied date.
- Client-side persistence using `localStorage`.

## Tech Stack
- **Framework**: React (Vite JS template)
- **Styling**: Vanilla CSS
- **Storage**: Browser `localStorage`
